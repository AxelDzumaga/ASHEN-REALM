# Ashen Realm — Character Art Standard

Especificación oficial para personajes de combate y sus reemplazos de arte.

## Dirección

- Estilo: cartoon-chibi dark fantasy mobile.
- Vista: 3/4 lateral orientada a combate.
- Cámara y perspectiva idénticas para player, companion, enemigos y boss.
- Proporción: cabeza grande, cuerpo compacto, manos y armas ligeramente exageradas.

## Render

- Outline oscuro, limpio y consistente.
- Cel shading suave con 2–3 niveles principales, sin microdetalle.
- Key light cálida de brasa.
- Rim light moderada.
- Detalle medio, priorizando silueta y lectura a tamaño de teléfono.
- Fondo del sprite transparente.

## Producción

- Pivot: centro inferior.
- Escala base player/enemigos normales: 512×512 px.
- Escala base boss: 768×768 px.
- Mismo grosor visual de outline y misma lógica de color en toda la familia.
- Los assets que no cumplan esta especificación se clasifican como PROVISIONALES hasta ser reemplazados o corregidos.
